Where entries are saved

Checking…

Every entry is saved instantly in this browser on this device. For a durable copy, click Connect log file once and pick (or create) a file such as gatehouse-log.json — put it on a shared network drive and every entry is written there too. Chrome or Edge required for this option; other browsers keep the in-browser copy and CSV export.

Backup & restore

Restoring merges entries and skips duplicates, so it is safe to import the same backup twice.

Danger zone

Download a backup first. This cannot be undone.

Setting up the gate house tablet

1. Keep this file on the tablet (or a shared drive) and open it in Chrome or Edge.
2. Bookmark it, or use browser menu → Install / Create shortcut so it opens full screen like an app.
3. In Settings, connect a log file on the shared drive.
4. Do not clear browsing data on this device — that removes the in-browser copy.
